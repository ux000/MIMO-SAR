# TDM-MIMO-SAR MATLAB 仿真说明

本项目围绕 Gao 等人 2021 年论文《MIMO-SAR: A Hierarchical High-resolution Imaging Algorithm for mmWave FMCW Radar in Autonomous Driving》，实现“回波生成 → MIMO 粗定位与 ROI → ROI 内 BP 精成像”的仿真链路，重点展示 TDM 发射时序、去斜回波相位、运动相位补偿和噪声的作用。代码使用中文注释，图的坐标、标题和图例使用中文。

本实现采用已知平台轨迹和逐 chirp 的精确 Tx—目标—Rx 双站 BP，保留论文的空间 ROI 层级思想。它没有实现论文每 K 个 chirp 构造 RVA 数据立方、选取最大速度分量再 BP 的时间压缩加速，也没有实现论文的 RANSAC 雷达里程计。因此，不能把运行时间、加速比或成像结果表述为论文的完整复现。

## 1. 运行方法

将 MATLAB 当前文件夹切换到本目录，打开 `run_demo.m` 并点击“运行”，即可生成结果并执行验收；也可以在命令窗口输入：

```matlab
run_demo
```

需要保留已有工作区变量时，可直接调用主函数，而不运行含有 `clear` 的演示脚本：

```matlab
out = main_tdm_mimo_sar;
report = validate_simulation(out);
```

改变输入信噪比或帧数：

```matlab
out = main_tdm_mimo_sar(struct('snrDb', 0, 'nFrames', 13));
```

无需 Radar Toolbox、Phased Array System Toolbox、Signal Processing Toolbox 或 Automated Driving Toolbox。本项目已在本机基础 MATLAB R2025a 中实测；绘图使用 `tiledlayout`、`exportgraphics`，未对其他 MATLAB 版本逐一测试。所有参数以 `default_config.m` 中的实际字段为准。修改参数后应重新生成回波和 ROI，避免使用上一次运行的结果。

默认将数据、报告和图片写入本目录的 `results` 子目录。连续比较不同配置时，为每次运行指定单独的目录，避免覆盖：

```matlab
out0 = main_tdm_mimo_sar(struct('snrDb', 0, ...
    'outputDir', fullfile(pwd,'results_snr0'), ...
    'figureVisible','off','saveRaw',false));
```

`saveRaw=false` 可以省去原始 ADC 文件；`figureVisible='off'` 可以后台出图。

| `plot_scene_geometry.m` | 独立绘制真实仿真场景、雷达轨迹与近邻目标局部放大图 |
| `validate_simulation.m` | 核对物理模型与成像链路 |

处理顺序为：

1. 建立静止散射点、平台运动和 2 发 4 收阵列。
2. 按“TX1 → TX2 → 下一循环 TX1”的顺序确定真实发射时刻。
3. 对每个发射时刻和接收通道计算传播时延，叠加各散射点回波并加入复高斯白噪声。
4. 距离 FFT 后，对同一发射天线的循环序列做多普勒处理；检测、峰值分组后再做 TDM 补偿和 MIMO 测角。
5. 将检测到的距离和角度映射到全局坐标，取多个小区域的并集构成 ROI。
6. 对 ROI 内的每个像素，按真实 Tx/Rx 位置计算双站路程，读取复数距离像并进行匹配相位补偿和相干累加。

## 4. 发射、回波与去斜相位

为避免直接对 77 GHz 载波进行超高采样率仿真，代码用解析复包络表达实际射频信号的传播相位。载频并未被省略，它通过 `fc*tau` 保留在去斜信号中。

`fmcw_waveform_demo.m` 另以 1.344 GHz 的复包络采样率显式生成一个 chirp 的 TX、延迟 RX 和 `TX.*conj(RX)` 混频结果，与解析 IF 逐点核对。该高采样率仅用于波形展示；主回波数据仍以 4 MHz IF ADC 采样率生成。发射 chirp 的扫频带宽为 336 MHz，不能用 4 MHz 的 IF ADC 采样率直接采样发射复包络。接收复包络保留 `exp(-j*2*pi*fc*tau)` 传播相位，并将回波到达之前的样本设为零。

发射 chirp 的解析形式为：

\[
s_T(t)=\exp\{j2\pi(f_ct+\tfrac12 S_wt^2)\}.
\]

对静止散射点 q、当前发射天线 m 和接收天线 r，按真实阵元位置计算：

\[
L_q=\|\mathbf p_q-\mathbf p_{T,m}\|+
\|\mathbf p_q-\mathbf p_{R,r}\|,\qquad \tau_q=L_q/c.
\]

接收信号为多个延迟 chirp 的线性叠加。本代码采用正拍频的去斜定义 `z = TX .* conj(RX)`：

\[
z(t)=\sum_q a_q\exp\left\{j2\pi
\left[S_w\tau_qt+f_c\tau_q-\tfrac12S_w\tau_q^2\right]\right\}+w(t).
\]

式中 `a_q` 为约定在去斜域的复散射系数。若从物理接收域定义复反射系数，则在上述混频约定下需要取其共轭。该约定影响复相位，不影响幅度定义；全过程必须保持一致。

三个相位项分别表示：

- `2*pi*Sw*tau*t`：拍频项，用于距离 FFT。
- `2*pi*fc*tau`：高敏感度传播相位，决定跨通道和跨孔径能否相干叠加。
- `-pi*Sw*tau^2`：剩余视频相位 RVP。保留它能使回波生成与匹配补偿严格一致。

阵元空间相位和平台运动相位已经包含在精确的 `L_q` 中，不应再额外叠加一次远场阵列相位或多普勒相位，否则会重复计入。代码采用单 chirp 内时延不变的 stop-and-go 假设，与论文式 (3)、式 (4) 的建模方式一致。跨 chirp 的时延随真实平台位置变化。

## 5. 两种运动相位补偿的不同用途

### 5.1 MIMO 测角前的 TDM 补偿

TDM 的两个 TX 在不同时刻发射。即使场景中的散射点静止，平台运动也使同一循环中 TX2 的相位相对 TX1 多出一个时间相位。直接把两组 RX 拼成虚拟阵列，会将这部分时间相位误认为空间到达角相位。

若当前去斜约定下测得有符号多普勒频率为 `fD`，第 m 个 TX 相对参考 TX 的发射时刻差为 `deltaT_m`，则测角前乘：

\[
C_{\mathrm{TDM},m}=\exp(-j2\pi\hat f_D\Delta t_m).
\]

对于两个 TX，TX2 的时差为 45 μs，恰好是同一 TX 慢时间周期 90 μs 的一半，因此它对应论文 II-B3 节所述的“半个多普勒相位补偿”。补偿方向由本项目的混频定义和 FFT 符号共同决定；更换混频方式时，不能只改其中一个符号。

### 5.2 SAR BP 的孔径传播相位补偿

BP 的任务是让同一候选像素来自不同平台位置、不同 TX/RX 的复回波同相相加。对候选像素计算 `L(x,y)` 后，用其对应延迟匹配距离像，并乘以传播相位的共轭。

若忽略距离 FFT 的有限采样窗细节，匹配相位可写为：

\[
C_{\mathrm{BP}}=\exp\{-j[2\pi f_c\tau-\pi S_w\tau^2]\}.
\]

实际实现还必须统一距离 FFT 的快时间参考点。令 `tCenter = (nSamples-1)/(2*fs)`，代码将距离 FFT 乘以 `exp(+j*2*pi*f*tCenter)`，消除频率栅格上与采样窗中心有关的相位斜坡。这样可以先对复数距离像进行稳定插值，但对应的有效参考频率变为 `fRef = fc + slope*tCenter`。最终匹配相位为：

\[
C_{\mathrm{BP}}=\exp\{-j2\pi(f_c+S_wt_\mathrm{Center})\tau
+j\pi S_w\tau^2\}.
\]

若直接对原始复数 FFT 栅格插值，有限栅格会使插值相位和幅度产生偏差。`range_compress.m` 与 `bp_image.m` 配套处理快时间相位参考和 RVP，不能只替换其中一个函数。

BP 对原始 TDM 通道使用真实发射时刻及阵元位置后，TDM 时间差已经进入几何匹配。MIMO 测角用的补偿系数不应再次乘到 BP 输入上，否则会重复补偿。

## 6. MIMO 如何决定 ROI

MIMO 粗定位从含噪回波出发，先得到距离—多普勒谱，再融合虚拟通道的非相干能量、执行 CA-CFAR 和峰值分组，对检测单元的通道复数向量做 TDM 补偿和测角。检测位置由 `x = r*sin(theta)`、`y = r*cos(theta)` 转换到全局坐标，再按一定余量扩展成矩形 ROI，多个 ROI 取并集。

ROI 构建使用检测结果，真实散射点坐标仅用于绘图和验证。两个方位上尚未分开的近点可落在同一个 ROI 中，随后由合成孔径 BP 分离；ROI 不需要在粗定位阶段就把两个点分开。

本项目的多通道谱融合、窗函数及 FFT 零填充使检测单元之间存在相关性。CA-CFAR 阈值因子属于工程近似，配置的虚警概率不能直接当作已经验证的实际虚警率。需要精确的虚警率时，应对噪声独立试验做 Monte Carlo 标定。

ROI 宽度需要覆盖角度估计误差、距离估计误差和未分辨散射点范围。ROI 过窄或低 SNR 漏检，会使 BP 根本不处理真实目标位置，之后再提高 BP 的相干积累能力也无法找回该目标。ROI 外的空白表示“未处理”，不能解释为“确认无目标”。

## 7. 噪声设置与结果解释

`snrDb` 表示加噪前全部仿真 IF 数据的平均信号功率与复白噪声功率之比。令平均信号功率为 `Ps`：

\[
\sigma_w^2=P_s10^{-\mathrm{SNR_{dB}}/10},\qquad
w=\sqrt{\sigma_w^2/2}(n_I+jn_Q),
\]

其中 `nI`、`nQ` 为相互独立的标准正态变量。该定义是整体输入 SNR，既不是每个散射点的 SNR，也不是距离 FFT 或 BP 后的输出 SNR。有限样本下实测 SNR 会有轻微波动。

当前随机噪声模型为复高斯白噪声。此外，代码有意设置 8 个通道的固定相位偏差，并默认使用已知标定值校正；`channelPhaseDeg` 和 `calibrateChannels` 可以控制这一项。标定值属于事先给定的硬件参数，不是从目标坐标反推的结果。其他雷达的非平稳互扰、窄带干扰、多径、地面杂波、随机通道漂移和发射机相位噪声尚未建模。

默认散射幅度按 `referenceRange^2/(Rtx*Rrx)` 衰减，并乘以各目标的固定复散射系数。将 `rangeAttenuation` 设为 `false` 可关闭此项距离衰减；目标反射系数不会在不同 chirp 之间随机改变相位。

主场景属于近侧视条件，径向速度较小，因此真实 TDM 补偿量也较小。另附的 `tdm_phase_demo.m` 使用 20° 单目标、远离为正的 8 m/s 径向速度和已知多普勒，单独展示补偿方向与角度偏差；这是受控相位验证，不参与主场景回波、ROI 或 BP，不应把它的显著补偿量当作默认主场景的实测效果。

降低 SNR 后，先观察粗检测和 ROI 是否仍覆盖目标，再观察 BP 的聚焦和旁瓣。增加帧数可以延长合成孔径并增加相干积累，但若轨迹误差使传播相位失配，帧数增加也可能加重散焦。论文 V-B 节讨论的 CPI 正是对这种可相干积累时长的约束。

## 8. 分辨率、零填充与验收

默认有效带宽 336 MHz 对应的名义距离分辨率约为 `c/(2B) = 0.446 m`。距离 FFT 零填充和更密的成像网格可以减小显示及插值步长，但不会把这项物理距离分辨率提高到厘米级。

13 帧的约 0.4 m 合成孔径远大于 8 通道 MIMO 的毫米级阵列孔径，所以横向分辨率主要由合成孔径提供。默认 5 m 处双点的横向间隔约 8.73 cm；是否清晰分开还受孔径加窗、旁瓣、SNR、目标相位和轨迹准确度影响。

建议按以下顺序检查结果：

1. 单点无噪声时，检查距离峰值位置与理论拍频 `Sw*L/c` 是否一致。
2. 检查同一 TX 的慢时间相位斜率与几何距离变化是否一致。
3. 在有明显径向速度的单点条件下，对比 TDM 补偿前后的测角峰值，确认符号正确。
4. 检查 MIMO ROI 覆盖率，确认它来自检测结果。
5. 对比 BP 匹配补偿与不匹配补偿结果，检查真实位置附近的聚焦和相干增益。
6. 用固定随机种子比较不同 SNR；统计虚警和漏检时另用多个独立噪声实现。

上述是物理和数值验收准则，不代表这些项目在任意改动参数后都自动通过。实际执行结果应以本目录附带的运行日志、验证报告和图片为准。

## 9. 变量维度和保存内容

| 变量 | 维度或内容 |
|---|---|
| `adc` | `[nSamples, nLoops, nTx, nRx, nFrames]`；默认 `[64,255,2,4,13]`，为复数去斜 ADC 数据 |
| `geom.time` | `[nLoops,nTx,nFrames]`；包含帧间空隙和 TX 时差的真实慢时间 |
| `geom.txOffset`、`geom.rxOffset` | 相对平台参考点的 TX/RX 沿 x 方向偏移，单位 m |
| `rc` | `[nRangeKept,nLoops,nTx,nRx,nFrames]`；范围由 `rangeLimits=[2,11]` m 截取，已做窗中心相位参考处理和可选通道标定 |
| `out.mimo.powerRV` | `[nRangeKept,nDopplerFFT]` 的通道融合功率谱 |
| `out.mimo.anglePower` | `[nRangeKept,nAnglesKept]` 的距离—角度功率图 |
| `out.mimo.detections` | 每行为 `[距离m,远离为正径向速度m/s,角度deg,全局xm,全局ym,功率,fD_Hz]` |
| `out.mimo.mask` | `[numel(y),numel(x)]` 的逻辑 ROI 掩膜，行对应 y、列对应 x |
| `out.image` | 正确相位补偿的复数 BP 图，与掩膜同尺寸 |
| `out.imageNoPhase` | 仍做距离插值，但不做传播相位匹配的对照图 |
| `out.imageTrajectoryError` | 使用错误 BP 轨迹的对照图，与另外两组使用同一份回波 |
| `out.bpStat.coherence` | `abs(相干和)/加权幅度和`，为 [0,1] 的相干系数；不是 SNR |

MATLAB 的 `squeeze` 会删除单例维度；检查数据时应按上述语义区分 TX、RX 和帧，避免因为某维长度为 1 而误判维度顺序。

`results` 中保存：

- `echo_data.mat`：`adc`、`geom` 和 `cfg`，仅在 `saveRaw=true` 时保存。
- `simulation_results.mat`：结构体 `out`，包括参数、检测、ROI、复数图和统计量，不重复保存 `rc`。
- `数值结果.txt`：实际 SNR、分辨率、孔径、ROI 像素比例、三次 BP 用时、TDM 受控实验和目标位置的 ROI 覆盖/相干系数。
- `验证结果.txt`、`validation_report.mat`：`validate_simulation` 的数值验收报告。
- `01_回波与距离压缩.png`：回波和距离处理。
- `02_MIMO检测与ROI.png`：MIMO 检测及 ROI。
- `03_BP相位补偿对比.png`：三种 BP 相位/轨迹设置的结果。
- `04_近邻目标剖面.png`：近邻目标横向剖面。
- `05_TDM相位补偿.png`：单目标受控 TDM 测角对比。
- `06_发射接收与混频.png`：显式发射、延迟接收复包络以及混频后的拍频波形。
- `07_仿真场景与雷达运动.png`、同名 `.fig`：等比例全局场景、雷达移动方向、轨迹和两个近邻目标的局部放大。可直接运行 `plot_scene_geometry` 独立生成，无需重新执行 BP。雷达从 `(0,0)` 沿 `+x` 以 1 m/s 运动，最后有效发射位置为 `(0.422505,0)` 米；目标均为静止点散射体。

ROI 的像素数减少比例只反映空间处理范围，不能当作整个算法的运行时间加速比。本项目没有运行整幅 BP 基线，也没有实现论文的 K-chirp 时间压缩，因而不报告论文的 115 倍加速。
